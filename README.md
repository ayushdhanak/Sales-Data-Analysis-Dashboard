# Sales Data Analysis Dashboard

## 1. Project Overview
This project focuses on analyzing sales data using Python and developing a professional dashboard using Microsoft Excel.

The dataset contains simulated sales records covering the period 2023–2025.

## 2. Project Objectives
- Analyze sales and profit performance.
- Identify monthly and yearly sales trends.
- Analyze product categories and regions.
- Identify top-performing products.
- Analyze customer segments and payment methods.
- Generate meaningful business insights.

## 3. Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Microsoft Excel

## 4. Project Workflow
Data Collection → Data Cleaning → Data Analysis → Visualization → Dashboard → Business Insights

## 5. Project Files
- `sales_data_raw.csv` – Original dataset
- `sales_data_cleaned.csv` – Cleaned dataset
- `Sales_Data_Analysis.ipynb` – Python analysis notebook
- `Sales_Analysis_Results.xlsx` – Analysis results
- `Sales_Analysis_Results_DashBoard.xlsx` – Excel dashboard
- `Ayush_Dhanak_Sales_Data_Analysis_Project_Report` – Final project report.
- `Ayush_Dhanak_Sales_Data_Analysis_Final_Presentation` – Final project presentation.

## 6. Key Business Insights
1. Technology was the highest sales-generating category.
2. West was the highest-performing region by sales.
3. Consumer customers contributed approximately 60.79% of total sales.
4. Credit Card recorded the highest sales among payment methods.
5. 2024 was the best-performing year.
6. Sales declined by approximately 12.09% in 2025 compared with 2024.

## 7. Conclusion
This project demonstrates the use of Python and Excel for data cleaning, sales analysis, visualization, and business reporting.
